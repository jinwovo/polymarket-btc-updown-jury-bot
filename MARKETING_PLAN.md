# Marketing Plan (30 days)

Goal: earn real stars from real users by improving discovery and trust.

## Week 1 - Packaging

- Finalize README with clear value and one-command start
- Add screenshots/GIF of:
  - live dashboard,
  - signal history,
  - paper trade history modal
- Publish `v0.1.0` release with changelog and known limitations

## Week 2 - Distribution

- Post technical thread:
  - X/Twitter
  - Reddit (`r/algotrading`, `r/cryptocurrency` where rules allow)
  - relevant Discord/Telegram dev channels
- Focus message:
  - real orderbook data, not fake simulation
  - fee-aware entry gate
  - reproducible backtest + paper sim

## Week 3 - Trust

- Add 3 benchmark datasets and expected outputs
- Add short demo video (2-3 minutes)
- Add issue labels and first `good first issue` tasks

## Week 4 - Retention

- Weekly release cadence (`v0.1.x`)
- Maintain response SLA for issues/PRs
- Improve onboarding based on top user friction points

## Metrics to watch

- GitHub Traffic (views, clones, referrers)
- README conversion: views -> stars ratio
- New issues from external users
- Returning contributors

## What not to do

- No fake stars, bought engagement, or bot interactions
- No misleading backtest claims
- No hidden assumptions in pnl reporting
